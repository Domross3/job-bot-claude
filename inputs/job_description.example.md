# Example Job Description

## Software Engineer Intern — Acme Corp

### About the role

We're looking for a Software Engineering Intern to join our Platform team for Summer 2025. You'll work on backend services that power our marketplace, contributing to API development, data pipelines, and system reliability.

### What you'll do

- Build and maintain RESTful APIs using Python and Flask
- Write SQL queries to support analytics and reporting features
- Collaborate with product managers and designers to ship new features
- Participate in code reviews and contribute to engineering best practices
- Help improve CI/CD pipelines and automated testing

### About you

- Pursuing a BS/MS in Computer Science or related field
- Proficient in Python and SQL
- Familiarity with web frameworks (Flask, Django, or FastAPI)
- Experience with Git and version control workflows
- Strong problem-solving skills and attention to detail

### Nice to have

- Experience with Docker and containerized deployments
- Exposure to cloud platforms (AWS, GCP)
- Interest in marketplace or e-commerce technology
